# TODOList应用视觉风格规范

## 1. 核心设计原则

- **简洁直观**：保持界面干净，避免冗余元素
- **一致性**：左右两侧使用统一的视觉语言
- **功能优先**：只实现明确要求的功能，不添加额外模块
- **现代感**：符合现代UI设计规范

## 2. 色彩系统

### 主色调
- **主色**: `#2563eb` (blue-600) - 用于主要操作按钮和强调元素
- **成功色**: `#10b981` (emerald-500) - 用于已完成任务
- **背景色**: `#f9fafb` (gray-50) - 应用主背景
- **表面色**: `#ffffff` (white) - 卡片和容器背景

### 中性色
- **文本主色**: `#1f2937` (gray-800)
- **文本次色**: `#6b7280` (gray-500)
- **边框色**: `#e5e7eb` (gray-200)
- **分割线**: `#f3f4f6` (gray-100)

## 3. 字体系统

### 字体家族
- **主字体**: 系统默认字体栈 (Inter, -apple-system, BlinkMacSystemFont, sans-serif)

### 字体大小
- **大标题**: 20px / font-bold
- **中标题**: 18px / font-semibold
- **小标题**: 16px / font-semibold
- **正文**: 14px / font-normal
- **小字**: 12px / font-normal

## 4. 间距系统

- **极小间距**: 4px
- **小间距**: 8px
- **中间距**: 16px
- **大间距**: 24px
- **超大间距**: 32px

## 5. 圆角规范

- **小圆角**: 4px - 用于输入框、按钮
- **中圆角**: 8px - 用于卡片
- **大圆角**: 12px - 用于模态框

## 6. 阴影系统

- **浅阴影**: `0 1px 2px 0 rgba(0, 0, 0, 0.05)` - 用于普通卡片
- **中阴影**: `0 4px 6px -1px rgba(0, 0, 0, 0.1)` - 用于悬浮状态
- **深阴影**: `0 10px 15px -3px rgba(0, 0, 0, 0.1)` - 用于模态框

## 7. 组件样式规范

### 7.1 编辑器区域（左侧）
- **背景**: `#ffffff`
- **边框**: `1px solid #e5e7eb`
- **圆角**: 8px
- **内边距**: 16px
- **字体**: 14px
- **行高**: 1.6

### 7.2 任务列表区域（右侧）
- **卡片背景**: `#ffffff`
- **卡片边框**: `1px solid #e5e7eb`
- **卡片圆角**: 8px
- **卡片内边距**: 16px
- **卡片间距**: 12px

### 7.3 复选框
- **未选中**: 空心圆角框，边框色 `#d1d5db`
- **已选中**: 蓝色背景 `#2563eb`，白色勾号

### 7.4 按钮
- **主按钮**: 蓝色背景 `#2563eb`，白色文字，4px圆角
- **悬停状态**: 背景色加深 `#1d4ed8`
- **次要按钮**: 白色背景，灰色边框

## 8. 布局规范

### 8.1 整体布局
- **页面背景**: `#f9fafb`
- **顶部导航栏**: 高度 64px，白色背景，底部边框
- **主内容区**: 左右分栏，各占 50%
- **左右间距**: 20px

### 8.2 响应式
- **桌面端**: 左右分栏并排显示
- **移动端**: 上下堆叠（如需要）

## 9. 交互状态

### 9.1 悬停状态
- **卡片**: 阴影加深，轻微上移
- **按钮**: 背景色加深
- **链接**: 颜色加深

### 9.2 聚焦状态
- **输入框**: 蓝色边框 `#2563eb`，2px外发光
- **按钮**: 保持悬停样式

### 9.3 激活状态
- **已完成任务**: 删除线，灰色文字，降低透明度
- **选中项**: 浅蓝色背景

## 10. 自动补全样式

### 补全弹窗
- **背景**: `#ffffff`
- **边框**: `1px solid #e5e7eb`
- **圆角**: 8px
- **阴影**: `0 10px 15px -3px rgba(0, 0, 0, 0.1)`
- **最大宽度**: 300px

### 补全项
- **内边距**: 10px 12px
- **悬停背景**: `#f3f4f6`
- **选中背景**: `#dbeafe`
- **标签字体**: 14px font-semibold
- **描述字体**: 12px text-gray-500
